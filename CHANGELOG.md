# V4 Changelog

## Timetable
- Added weekly schedule and daily visit planning.
- Added due-but-unscheduled member list.
- Added 2-week, 4-week, custom date and no-repeat completion choices.

## Leads
- Added upcoming nearby-run suggestion on lead pages.
- Added nearby lead suggestions inside each scheduled day.

## Routes
- Daily routes start from current location and finish at home.
- Added optional Google Routes waypoint optimisation.
- Added local return-home-aware fallback optimisation.
- Added final Navigate Home stage.

## Reminders
- Added message preview, copy and open-in-phone-Messages actions.
- Added optional Twilio sending.
- Added automatic Vercel Cron checks with duplicate protection.

## Data
- Added Appointments and expanded Settings support.
- Missing Google Sheet tabs are created automatically.
- Existing NextVisit values migrate into appointments.
